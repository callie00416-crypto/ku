# moteus 项目目录结构与文件说明

本文档对 `moteus-main/moteus-main/` 子目录下的所有文件进行介绍。moteus 是 mjbots 公司开发的高性能无刷伺服控制器软硬件完整开源项目，包含固件、PCB 设计、客户端软件（Python/C++/Rust）以及诊断工具。

仓库结构按用途划分为 7 个主要目录：`.github/`、`configs/`、`docs/`、`fw/`、`hw/`、`lib/`、`tools/`、`utils/`。
本目录之外的根级文件如 `README.md`、`LICENSE`、`BUILD`、`WORKSPACE`、`mkdocs.yml` 等则属于 Bazel 构建系统、文档站点配置以及项目元数据。

## 十、文件总数与体积概览

- 总目录数（含隐藏）：约 95 个
