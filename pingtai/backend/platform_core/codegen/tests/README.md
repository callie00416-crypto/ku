# 代码生成测试目录

## 📋 目录说明

本目录包含代码生成系统的测试脚本，用于验证代码生成功能和模板渲染效果。

## 🧪 测试文件列表

### 模板测试

- **test_enhanced_template.py** - 增强模板测试
  - 测试增强模板功能
  - 验证模板渲染效果
  - 适合模板开发验证

- **test_protocol_example.py** - 协议示例测试
  - 测试协议示例生成
  - 验证协议实现
  - 适合协议验证

## 🚀 使用指南

### 增强模板测试

测试增强模板功能：

```bash
cd backend/platform/codegen/tests
python test_enhanced_template.py
```

**测试内容**:
- 模板语法验证
- 变量替换测试
- 条件渲染测试
- 循环渲染测试
- 继承机制测试

### 协议示例测试

测试协议示例生成：

```bash
cd backend/platform/codegen/tests
python test_protocol_example.py
```

**测试内容**:
- 协议规范解析
- 代码生成验证
- 接口实现验证
- 文档生成验证

模板开发需要注意：

1. **语法正确**：使用正确的Jinja2语法

3. **错误处理**：添加适当的错误处理
4. **性能优化**：优化模板渲染性能

### 代码生成

4. **测试覆盖**：生成充分的测试
