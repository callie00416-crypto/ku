# ATA-101B实际设备测试指南

## 🎯 测试目的

连接实际的ATA-101B功率放大器设备，设置各种参数，观察显示屏的变化，验证设备功能。

## 📋 测试前准备

### 1. 硬件准备

- ✅ ATA-101B功率放大器设备
- ✅ USB数据线（设备自带）
- ✅ 电源线
- ✅ 信号源（可选，用于测试输出）

### 2. 软件准备

- ✅ Python 3.11+
- ✅ pyserial库（已安装）
- ✅ ATA-101B驱动（已生成）
- ✅ 测试脚本（已创建）

### 3. 连接步骤

1. **连接电源**
   - 将电源线连接到ATA-101B
   - 打开设备电源开关
   - 等待设备启动完成

2. **连接USB**
   - 将USB数据线连接到电脑
   - 设备会自动识别为USB虚拟串口
   - 注意：设备使用CDC-ACM协议

3. **确认串口号**
   - 打开设备管理器
   - 查找"端口(COM和LPT)"
   - 记录USB串口号（通常是COM3）
   - 或者使用USB设备检测工具

## 📊 测试参数说明

### 增益参数

| 值 | 显示 | 说明 |
|----|------|------|
| 0dB | AMP: 0000 | 无增益 |
| 2dB | AMP: 0002 | 2倍增益 |
| 10dB | AMP: 0010 | 10倍增益 |
| 20dB | AMP: 0020 | 100倍增益 |

### 输入电阻

| 值 | 显示 | 说明 |
|----|------|------|
| 50Ω | RIN: 0050 | 标准输入阻抗 |
| 1000Ω | RIN: 1000 | 高输入阻抗 |

### 输出电阻

| 值 | 显示 | 说明 |
|----|------|------|
| 1.5Ω | ROT: 0015 | 低输出阻抗 |
| 50Ω | ROT: 0500 | 标准输出阻抗 |

### 输出状态

| 状态 | 显示 | 说明 |
|------|------|------|
| 打开 | AON | 输出使能 |
| 关闭 | AOF | 输出禁用 |

## 🖥️ 显示屏观察要点

### 正常显示

设备显示屏应该显示以下信息：

1. **当前增益**: 显示设置的增益值
2. **输入电阻**: 显示设置的输入电阻
3. **输出电阻**: 显示设置的输出电阻
4. **输出状态**: 显示输出是否打开
5. **设备状态**: 显示设备运行状态

### 观察步骤

1. **初始状态**
   - 查看默认参数
   - 确认设备正常工作

2. **参数变化**
   - 每次设置参数后
   - 观察显示屏是否更新
   - 确认显示值与设置值一致

3. **输出控制**
   - 打开输出时观察指示灯
   - 关闭输出时观察指示灯
   - 确认输出状态正确

4. **保存设置**
   - 保存后重新上电
   - 确认设置被保存

## 🔍 故障排除

### 常见问题

#### 1. 设备连接失败

**症状**: 提示"设备连接失败"

**可能原因**:
- USB连接问题
- 设备未上电
- 串口号错误
- USB驱动未安装

**解决方法**:
```bash
# 检查USB连接
# 确认USB数据线连接正常
# 确认设备电源已打开

# 检查串口号
# Windows: 设备管理器 -> 端口(COM和LPT)
# Linux: ls /dev/ttyUSB*

# 尝试不同的串口号
cd backend/projects/encoder_test/drivers/device/power_amplifier/tests
python test_comprehensive.py

# 检查USB驱动
# Windows: 设备管理器 -> 通用串行总线设备
# Linux: lsusb
```

#### 2. 设备无响应

**症状**: 发送命令后设备无响应

**可能原因**:
- ⚠️ **最常见问题**：缺少CRLF回车换行符
- 命令格式错误
- 通信参数不匹配

**解决方法**:
```bash
# 测试回车换行符配置
cd backend/projects/encoder_test/drivers/device/power_amplifier/tests
python test_newline_simple.py

# 验证命令格式
# 正确：ATA,SET,AON,0000;\r\n
# 错误：ATA,SET,AON,0000;
# 错误：ATA,SET,AON,0000;\n
# 错误：ATA,SET,AON,0000;\r

# 检查通信参数
# 波特率: 9600
# 数据位: 8
# 停止位: 1
# 校验位: 无
```

#### 3. 参数设置失败

**症状**: 提示"参数设置失败"或"OVER RANGE ERROR!"

**可能原因**:
- 参数值超出范围
- 参数类型错误
- 设备响应异常

**解决方法**:
```bash
# 检查参数范围
# 增益: 0-20dB, 步进2dB
# 输入电阻: 50Ω 或 1000Ω
# 输出电阻: 1.5Ω 或 50Ω

# 使用协议测试
cd backend/projects/encoder_test/drivers/device/power_amplifier/tests
python test_protocol_direct.py
```

#### 4. 显示屏无变化

**症状**: 设置参数后显示屏无变化

**可能原因**:
- 命令未正确发送
- 回车换行符配置错误
- 设备响应异常

**解决方法**:
```bash
# 检查设备状态
# 确认设备正常工作
# 重新连接设备

# 测试回车换行符
cd backend/projects/encoder_test/drivers/device/power_amplifier/tests
python test_newline_simple.py

# 测试屏幕显示
cd backend/projects/encoder_test/drivers/device/power_amplifier/tests
python test_screen_display.py
```

#### 4. 串口占用

**症状**: 提示"串口已被占用"

**可能原因**:
- 其他程序正在使用串口
- 之前的程序未正常关闭

**解决方法**:
```bash
# Windows: 关闭占用串口的程序
# Linux: 检查并关闭占用进程
lsof /dev/ttyUSB0
kill -9 <PID>
```

## 🎓 测试技巧

### 1. 逐步测试

建议按照以下顺序逐步测试：

1. 先测试基本连接
2. 再测试单个参数
3. 最后测试组合参数

### 2. 对比测试

每次设置参数后：

1. 记录设置值
2. 观察显示值
3. 对比两者是否一致
4. 记录测试结果

### 3. 异常处理

遇到异常时：

1. 记录错误信息
2. 检查设备状态
3. 查看日志输出
4. 尝试重新连接

### 4. 性能测试

可以测试以下性能指标：

1. 响应时间：从发送命令到显示屏更新的时间
2. 稳定性：长时间运行是否稳定
3. 可靠性：多次重复设置是否一致
