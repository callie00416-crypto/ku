2. **错误响应字符串**

   - 正确: `OVER RANGE ERROR!`

## 协议参考

### 通信参数
| 参数 | 值 |
|------|-----|
| 波特率 | 9600 |
| 发送码 | ASCII 码 |
| 校验位 | 无 |
| 数据位 | 8 |
| 停止位 | 1 |
| 流控制 | 无 |

### 指令集
| 序号 | 指令功能 | 指令内容 | 备注 |
|------|----------|----------|------|
| 1 | 输出开 | ATA,SET,AON,0000; | |
| 2 | 输出关 | ATA,SET,AOF,0000; | |
| 3 | 保存设置 | ATA,SET,SAV,0000; | |
| 4 | 输入电阻设置 | ATA,SET,RIN,0050; | "0050"为 50Ω<br>"1000"为 1000Ω |
| 5 | 输出电阻设置 | ATA,SET,ROT,0500; | "0015"为 1.5Ω<br>"0500"为 50Ω |
| 6 | 增益设置 | ATA,SET,AMP,0020; | "0000"为 0dB<br>"0012"为 12dB<br>"0020"为 20dB |

### 响应
- 设置成功: `SET DONE!`
- 设置越界: `OVER RANGE ERROR!`
- 设置指令错误: `SET ERROR!`

## 调试流程

### 基础调试流程

1. **硬件连接**
   - 将功放的 RS485 接口连接到电脑
   - 确认串口名称（Windows: COMx, Linux: /dev/ttyUSBx）

2. **环境准备**
   ```powershell
   # 进入后端目录
   cd backend
   
   # 确保依赖已安装
   pip install pyserial
   ```

3. **配置串口**
   - 编辑调试脚本，修改 `SERIAL_PORT` 变量
   - 确认波特率设置为 9600

4. **运行测试**
   ```powershell
   # 自动化测试
   python test_power_amplifier.py
   
   # 或交互式测试
   python test_power_amplifier_interactive.py
   ```

5. **检查结果**
   - 查看控制台输出
   - 检查功放设备的实际响应
   - 确认所有测试通过

### 完整工作流程测试

1. 设置增益为 20dB
2. 设置输入电阻为 1000Ω
3. 设置输出电阻为 50Ω
4. 打开输出
5. 保存设置
6. 关闭输出

## 常见问题

### 1. 串口打开失败

**问题**: `串口打开失败` 或 `Access denied`

**解决方案**:
- 检查串口是否被其他程序占用
- 确认串口名称正确
- 尝试关闭其他可能使用该串口的程序
- 使用串口助手工具验证串口可用性

### 2. 设备无响应

**问题**: 发送命令后没有响应

**解决方案**:
- 检查硬件连接是否牢固
- 确认波特率设置正确（9600）
- 检查 RS485 接线是否正确（A/B 线）
- 使用串口调试助手验证通信

### 3. 参数设置失败

**问题**: 返回 `SET ERROR!` 或 `OVER RANGE ERROR!`

**解决方案**:
- 检查参数值是否在有效范围内
- 增益: 0-20dB，步进 2dB
- 输入电阻: 50Ω 或 1000Ω
- 输出电阻: 1.5Ω 或 50Ω

### 4. 权限错误

**问题**: `Permission denied` (Linux/macOS)

**解决方案**:
```bash
# 将用户添加到 dialout 组
sudo usermod -a -G dialout $USER

# 重新登录或重启
```
